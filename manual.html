高速ファイル検索 (Fast File Search) 操作マニュアル

指定した親フォルダ配下を爆速で並列走査し、メモリ上から数万〜数十万件のファイルを瞬時にインクリメンタル絞り込みする超軽量デスクトップ検索ツールです。 タブ機能で複数フォルダを並行してスキャン・検索でき、フォルダを切り替えるたびの再検索を減らせます。

🚀 1. はじめに・特徴

Windows標準の検索機能で起きがちな「検索が遅い」「インデックスが不安定」「思うように引っかからない」という課題を根本から解決するために開発されました。

⚡

並列走査 ＆ ストリーミング

Rayonによるマルチスレッド並列走査を採用。スキャン完了を待たずに、見つかったファイルから即座に画面へ反映されリアルタイム検索が可能です。

🧠

インメモリ・非同期検索

走査したファイル群をメモリにキャッシュし、バックグラウンドの検索ワーカースレッドで探索。GUI描画を一切ブロックせず、入力レスポンスは常に軽快です。

🔍

日本語・AND / OR / NOT 完全対応

全角スペースも半角として扱い、大文字小文字を自動正規化。スペースでAND、|でOR、!や-で除外検索が自由自在です。

📋

実務直結のワンクリック操作

各行左端の「📋」ボタンで、置き場所のフォルダパスを即コピー。エクスプローラー連携や対象フォルダの深掘り検索も即座に行えます。

🖱️

OLEドラッグ＆ドロップ / 複数選択

Ctrl・Shift で複数行を選択し、そのままエクスプローラーやメール、他アプリへドラッグしてファイルをコピー。クリップボード経由の一括コピー（Ctrl+V で貼り付け）にも対応します。

🗂️

タブで複数フォルダを並行検索

タブを増やすだけで別フォルダのスキャン・検索を同時に進められます。タブを切り替えても結果は保持されるため、同じフォルダへの再検索・再スキャンが不要です（Ctrl+T / Ctrl+W で素早く開閉）。

🗂️ 3. タブ機能（複数フォルダの同時検索）

タブを使うと、フォルダを切り替えるたびに再スキャン・再検索する手間を減らせます。各タブは検索対象フォルダ・走査結果・検索クエリ・選択状態・ソート・種別フィルタをそれぞれ独立して保持します。

操作 方法 備考
新しいタブを開く タブバー右端の「＋」をクリック、または Ctrl+T 現在のタブの検索対象フォルダを引き継いだ状態で開きます。
タブを閉じる タブの「✕」をクリック、または Ctrl+W 最後の1枚のタブは閉じられません。
タブを切り替える タブをクリック 切り替えても検索結果・スキャン進捗はそのまま保持され、再スキャンは発生しません。
💡
複数タブは同時にスキャンされます
タブを切り替えなくても、他タブのスキャンはバックグラウンドで並行して進みます（走査中のタブには「⚡」マークが表示されます）。ただし走査用スレッドはアプリ全体で共有しているため、同時に多数のタブを大量スキャンすると、CPU・ディスクI/Oを取り合って個々の速度は遅くなります。
⚠️
タブの構成はアプリ再起動後に復元されません
お気に入り・検索履歴・最後に開いていたフォルダ（1つ分）やソート・種別フィルタ・列幅の既定値は保存されますが、開いていたタブの枚数や中身は次回起動時には引き継がれません。

📖 4. 基本的な使い方

  1. 1
    検索対象の親フォルダを指定する

    画面上部の「📁 検索対象」欄にパスを直接入力するか、右側の「📂 参照...」ボタンを押して検索したいフォルダ（プロジェクトフォルダや作業ディレクトリなど）を選択します。
    ※ サイドバーの「お気に入り」や「検索履歴」をクリックすることでも即座に対象を切り替えられます。

  2. 2
    バックグラウンド走査が自動開始

    フォルダが指定されると自動的に並列走査がスタートします。
    走査の完了を待つ必要はありません。 読み込まれたファイルから順次メモリに登録され、即座に検索が可能です。

  3. 3
    「🔍 検索」バーにキーワードを入力

    検索バーに探したい単語を入力すると、キーを叩くたびにリアルタイムで候補が絞り込まれます。
    IMEの確定Enterキーを押してもフォーカスが外れず、確定した文字が選択状態のまま残らない設計になっているため、日本語入力もストレスなく続けて入力できます。

  4. 4
    ファイルを開く / パスをコピーする

    目的のファイルが見つかったら、以下のいずれかの操作を行います：

    • 左端の「📋」ボタン：置き場所のフォルダパスをコピー（ファイル名は含みません）
    • ダブルクリック：既定のアプリケーションでファイルを開く
    • 行を選択して Enter：選択中の項目を開く
    • ドラッグ＆ドロップ：エクスプローラーや他アプリへ直接ファイルをコピー
    • 右クリック：フルパスのコピー、ファイル本体のコピー、エクスプローラーで表示、親フォルダの再検索など

⚡ 5. 高度な検索クエリ仕様

検索クエリエンジンは強力な構文解析を備えており、大文字小文字の区別なく、スペースや記号を組み合わせた柔軟な絞り込みが可能です。

検索モード 構文・記号 クエリ入力例 動作とマッチング条件
AND検索 スペース / 全角空白 Rust 2026 PDF 入力したすべての単語を含む項目に絞り込みます（全角スペースも自動的にAND扱いとなります）。
OR検索 | （パイプ記号） png|jpg|webp いずれかの単語が含まれている項目がヒットします。拡張子の一括絞り込みなどに最適です。
NOT（除外）検索 ! または - !node_modules -target 指定した単語を含むファイル・パスを除外します。ノイズとなるフォルダを省く際に有効です。
パス指定検索 / または \ を含む単語 src/ query スラッシュまたはバックスラッシュを含む単語は、ファイル名だけでなく親フォルダパス全体を対象にマッチングします。
複合検索 上記すべての組み合わせ report 2026 pdf|xlsx !draft 「report」かつ「2026」を含み、「pdf または xlsx」のいずれかであり、「draft」を含まない項目を絞り込みます。

💡 実践クエリ例

rust cargo | toml 「rust」を含み、かつ「cargo または toml」を含むファイル
design !png !jpg 「design」を含み、PNG画像とJPG画像を除外した一覧
src\ components | views srcフォルダ配下の components または views にあるファイル
💡
大文字・小文字は完全自動無視
PDF と入力しても pdf と入力しても同一視されます。全角英数や全角スペースも内部で自動的に正規化されます。

⏸️ 6. スキャン制御（一時停止・再開・最初から）

膨大なファイルが存在するフォルダをスキャンする際、状況に合わせて柔軟に走査をコントロールできます。

⏸ 一時停止 (Pause)

走査中のバックグラウンドスレッドを即座に休止させます。
一時停止中も、それまでに読み込まれたファイルを使って自由に検索・ソート・コピーが可能です。 ディスク負荷を一時的に下げたい時に便利です。

▶ 再開 (Resume)

一時停止していた地点から、即座に走査を再開します。最初からやり直す必要はありません。

🔄 最初から / 再スキャン

現在のキャッシュをすべて破棄し、指定フォルダを最初からクリーンに再走査します。ファイルの追加・削除があった場合に使用します。

⭐ 7. お気に入り＆検索履歴の活用

画面左側のサイドバーでは、頻繁に利用するフォルダへの素早いアクセスをサポートします。

⭐ お気に入りフォルダの登録・削除

  • 追加方法：検索対象フォルダを指定した状態で、上部バーの「☆ お気に入り」ボタンをクリック（登録されると「⭐ 登録済」に変化します）。
  • 呼び出し：サイドバーのお気に入り一覧からフォルダ名をクリックするだけで、即座に対象が切り替わり走査・検索が開始されます。
  • 削除方法：各お気に入り項目の右端にある「✕」ボタンをクリックします。

🕒 検索履歴

  • 過去にスキャンしたフォルダが最大15件まで自動的に記録されます。
  • 履歴をクリックすれば即座にそのフォルダを再検索できます。
  • 履歴をリフレッシュしたい場合は、セクション右側の「🗑 クリア」ボタンを押します。
ℹ️
サイドバーの開閉
画面左上の「◀ サイドバー」ボタンを押すことで、サイドバーを折りたたんで検索テーブルを全画面に広げることができます。状態はアプリ終了後も自動保存されます。

🔃 9. 並び替え・種別フィルタ・列幅

検索結果テーブルのヘッダーをクリックすることで、並び順を瞬時に切り替えられます。

📅 更新日時 (デフォルト: 新しい順)

ヘッダーの「📅 更新日時」をクリックすると、▼ 新しい順 ⇄ ▲ 古い順 が切り替わります。直近で作業したファイルを探す際に最も強力です。

📄 ファイル名

ヘッダーの「📄 ファイル名」をクリックすると、▲ 昇順 (A→Z / あ→ん) ⇄ ▼ 降順 (Z→A / ん→あ) が切り替わります。

📂 パス名

ヘッダーの「📂 パス」をクリックすると、ディレクトリパス順で ▲ 昇順 ⇄ ▼ 降順 が切り替わります。同じフォルダのファイルをまとめて見たいときに便利です。

🗂 種別フィルタ

検索バーの右にある 3 つのトグルで、一覧に出す対象を切り替えられます。クエリを変えずに絞り込めるので、「フォルダだけ探したい」といった場面で有効です。

  • 📁 フォルダのみ：ディレクトリだけを表示
  • 📄 ファイルのみ：ファイルだけを表示
  • 🗂 両方：制限なし（既定）

↔ 列幅の調整

テーブル中央の縦の境界線をドラッグすると、左ペイン（ファイル名＋更新日時）と右ペイン（フォルダパス）の幅を変えられます。ダブルクリックで既定幅（420px）に戻ります。 調整した幅はアプリ終了後も保存されます。

❓ 10. よくある質問・設定情報

Q. 設定やお気に入り・履歴データはどこに保存されますか？

Windowsの標準AppData領域に JSON 形式で自動保存されます：
C:\Users\<ユーザー名>\AppData\Roaming\Antigravity\FileSearchApp\config.json

※ アプリを閉じても、最後に開いていたフォルダ、お気に入り、検索履歴（最大15件）、ソート状態、種別フィルタ、列幅、サイドバー開閉状態がそのまま復元されます。開いていたタブの枚数・構成だけは保存対象外で、次回起動時は常に1タブから始まります（検索したフォルダは履歴に残るため、そこから素早く再度開けます）。

Q. 大量（数十万件）のファイルをスキャンしても重くなりませんか？

本アプリは以下の最適化により、大量ファイル時も軽快に動作します：

  • Windowsネイティブキャッシュ走査：ファイルメタデータを取得する追加システムコールを抑制。
  • 非同期検索ワーカースレッド：探索とソートをUIスレッドから完全分離。
  • Top-N 部分ソート：上位件数（デフォルト500件）のみを計算する select_nth_unstable_by を採用。
  • 更新間引き：走査中の結果反映は件数に応じて 150ms〜500ms 間隔にまとめ、走査スレッドとCPUを奪い合わないようにしています。
  • 仮想スクロール描画：画面内に見えている行だけをレンダリング。

Q. ドラッグ＆ドロップでファイルが移動してしまいませんか？

移動しません。本アプリが許可しているドロップ効果はコピーのみです。ドロップ先で作られるのは複製で、検索元のファイルはそのまま残ります。ドラッグを途中でやめたいときは Esc キーを押してください。

Q. ファイルの中身（全文検索・Grep）はできますか？

本ツールは「ファイル名およびパス名による超高速絞り込み」に特化して極限までチューニングされています。ファイルの中身の検索は行わないため、ディスクやメモリを圧迫せず瞬時の応答が可能です。

⚠️
アクセス権限について
管理者権限が必要なシステムディレクトリ（C:\Windows\System32 等の一部）はOSによりスキップされる場合があります。その場合、下部ステータスバーに「警告あり」として通知されます。通常のユーザーファイル・作業フォルダは問題なく全走査されます。
